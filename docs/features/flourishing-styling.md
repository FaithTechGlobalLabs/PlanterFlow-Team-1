# Styling hooks for the flourishing UI

Use component roots with `component__element` names and `component--state` modifiers. Keep existing `ff-`, `garden-` and `planter-` prefixes. Tailwind utilities remain appropriate for shared layout and token-based styling; named classes provide stable hooks for component-specific changes.

| Component        | Root                                                                        | Element hooks                                                                                                                                                                              |
| ---------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Church tree      | `church-tree`, `church-tree--seed/sprout/sapling/young/established/unknown` | `__shadow`, `__structure`, `__roots`, `__seed`, `__stem`, `__trunk`, `__canopy`, `__texture-leaf`, `__objective-branch`, `__progress-leaf`, `__fruit`, `__fruit-body`, `__fruit-highlight` |
| Tree meaning     | `church-growth`                                                             | `__summary`, `__meaning`, `__toggle`, `__explanation`; explanation modifiers `--roots/age/progress/outcomes/quiet/corrections`                                                             |
| Church journey   | `church-journey`                                                            | `__title`, `__summary`, `__list`, `__moment`, `__date`, `__description`, `__empty`, `__more`                                                                                               |
| Account menu     | `ff-account`                                                                | `__trigger`, `__avatar`, `__name`, `__chevron`, `__panel`, `__identity`, `__preview-note`, `__form`, `__action`                                                                            |
| PDF export       | `ff-export`                                                                 | `__button`, `__spinner`, `__icon`, `__label`, `__error`                                                                                                                                    |
| Input/select     | `ff-field`, `ff-field--input/select`                                        | `__label`, `__control`, `__error`                                                                                                                                                          |
| Form card        | `ff-form-card`                                                              | `__title`, `__description`                                                                                                                                                                 |
| Page heading     | `ff-page-header`                                                            | `__eyebrow`, `__title`, `__subline`                                                                                                                                                        |
| Shared actions   | `ff-action`, `ff-action--primary/secondary/tertiary/destructive`            | Native disabled state and focus-visible                                                                                                                                                    |
| Status label     | `ff-status-label`                                                           | Semantic text; supported status identifiers, not display strings, determine status classes elsewhere                                                                                       |
| Partner branding | `send-network-logo`                                                         | Shell-specific `garden-topbar__partner-logo` / `planter-topbar__partner-logo`; grouped in `*-topbar__actions`                                                                              |

Church Journey owns and imports `church-journey.css`; tree artwork/meaning use `tree.css`; Account Menu owns and imports `account-menu.css`. Every styled child has an explicit class. Account name styling no longer relies on `nth-child`, and Journey/meaning styling does not rely on descendant tag selectors.

Use semantic tokens from `globals.css`; keep artwork palette scoped to `church-tree`. Prefer one-class selectors, pseudo-classes for interaction (`:hover`, `:focus-visible`, `:disabled`, `[open]`) and valid ARIA attributes for meaning. Do not depend on child order, anonymous spans or broad global element overrides. Preserve native dialog/details behavior, keyboard focus, existing reduced-motion handling and permission-aware data.
